## HTML-разметка

HTML используется для создания структуры страницы.

Пример основной структуры:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Калькулятор</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <main class="calculator-page">
        <section class="calculator">
            <h1 class="calculator-title">Калькулятор</h1>

            <div class="calculator-screen">
                0
            </div>

            <div class="calculator-buttons">
                <button class="calculator-button">7</button>
                <button class="calculator-button">8</button>
                <button class="calculator-button">9</button>
                <button class="calculator-button calculator-button--operation">+</button>

                <button class="calculator-button">4</button>
                <button class="calculator-button">5</button>
                <button class="calculator-button">6</button>
                <button class="calculator-button calculator-button--operation">-</button>

                <button class="calculator-button">1</button>
                <button class="calculator-button">2</button>
                <button class="calculator-button">3</button>
                <button class="calculator-button calculator-button--operation">*</button>

                <button class="calculator-button calculator-button--clear">C</button>
                <button class="calculator-button">0</button>
                <button class="calculator-button calculator-button--equal">=</button>
                <button class="calculator-button calculator-button--operation">/</button>
            </div>
        </section>
    </main>
</body>
</html>
```

В разметке используются следующие теги:

| Тег | Назначение |
|---|---|
| `html` | Корневой элемент HTML-документа |
| `head` | Служебная информация страницы |
| `meta` | Указание кодировки |
| `title` | Название вкладки браузера |
| `link` | Подключение CSS-файла |
| `body` | Видимая часть страницы |
| `main` | Основное содержимое страницы |
| `section` | Логический блок калькулятора |
| `h1` | Заголовок страницы |
| `div` | Контейнеры для экрана и кнопок |
| `button` | Кнопки калькулятора |

## CSS-стили

CSS используется для визуального оформления калькулятора.

Пример стилей:

```css
body {
    margin: 0;
    padding: 0;

    background-color: #f5f5f5;
    font-family: Arial, Helvetica, sans-serif;
}

    min-height: 100vh;
    display: flex;
    align-items: center;
    justify-content: center;
    padding: 30px;
}

.calculator {

    background-color: #ffffff;
    border: 2px solid #d32f2f;
    border-radius: 24px;
    padding: 24px;
    box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12);
}

.calculator-title {
    margin: 0 0 20px 0;
    color: #d32f2f;
    text-align: center;
}

.calculator-screen {
    min-height: 70px;
    background-color: #fff0f0;
    border-radius: 16px;
    padding: 16px;
    margin-bottom: 20px;
    font-size: 32px;
    font-weight: bold;
    color: #333333;
    text-align: right;
}

.calculator-buttons {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 12px;
}

.calculator-button {
    border: 2px solid #d32f2f;
    border-radius: 16px;
    background-color: #ffffff;
    color: #d32f2f;
    padding: 16px;
    font-size: 20px;
    font-weight: bold;
    cursor: pointer;
    transition: 0.2s;
}

.calculator-button:hover {
    background-color: #d32f2f;
    color: #ffffff;
    transform: translateY(-2px);
}

.calculator-button--operation {
    background-color: #fff0f0;
}

.calculator-button--equal {
    background-color: #d32f2f;
    color: #ffffff;
}

.calculator-button--clear {
    background-color: #333333;
    border-color: #333333;
    color: #ffffff;
}
```

Основные CSS-свойства:

| Свойство | Назначение |
|---|---|
| `display: flex` | Центрирование калькулятора на странице |
| `display: grid` | Размещение кнопок в сетке |
| `grid-template-columns` | Создание четырёх колонок кнопок |
| `gap` | Расстояние между кнопками |
| `padding` | Внутренние отступы |
| `margin` | Внешние отступы |
| `border` | Рамка элементов |
| `border-radius` | Скругление углов |
| `box-shadow` | Тень карточки калькулятора |
| `background-color` | Цвет фона |
| `color` | Цвет текста |
| `transition` | Плавное изменение стилей |
| `transform` | Смещение кнопки при наведении |
| `cursor: pointer` | Курсор в виде руки при наведении |

## Цветовая схема

Для оформления использовалась красно-белая цветовая схема, похожая на стиль государственных и социальных сервисов.

Основные цвета:

|---|---|---|

| Красный | `#d32f2f` | Основной акцент, рамки, кнопки |
| Тёмно-красный | `#b71c1c` | Hover-эффекты |

Пример использования цвета:

```css
.calculator {
    background-color: #ffffff;
    border: 2px solid #d32f2f;

    color: #d32f2f;
}

.calculator-screen {
    background-color: #fff0f0;
```

```css
.calculator-button:hover {
    background-color: #d32f2f;
    color: #ffffff;

```

При наведении кнопка меняет цвет и немного поднимается вверх. Это делает интерфейс более интерактивным.

### Основные составляющие Web

Основные составляющие Web:

1. **Клиент**

   Клиентом чаще всего является браузер. Он отправляет запросы серверу и отображает полученные данные пользователю.

2. **Сервер**

   Сервер принимает запросы от клиента, обрабатывает их и возвращает ответ.

3. **HTTP/HTTPS**

   Протоколы, по которым клиент и сервер обмениваются данными.

4. **HTML**

   Язык разметки, который задаёт структуру web-страницы.

5. **CSS**

   Язык стилей, который отвечает за внешний вид страницы.

6. **JavaScript**

   Язык программирования, который делает страницу интерактивной.

7. **URI/URL**

   Адрес ресурса в сети.

8. **DNS**

   Система, которая преобразует доменное имя сайта в IP-адрес сервера.

### Что такое URI

**URI** — Uniform Resource Identifier, то есть унифицированный идентификатор ресурса.

URI используется для идентификации ресурса в сети.

Пример URI:

```text
https://example.com/catalog/item?id=5
```

Он может включать:

| Часть | Пример | Описание |
|---|---|---|
| Схема | `https` | Протокол доступа |
| Домен | `example.com` | Имя сервера |
| Путь | `/catalog/item` | Путь к ресурсу |
| Query-параметры | `?id=5` | Дополнительные параметры |

URL является разновидностью URI, которая не только идентифицирует ресурс, но и показывает, где он находится и как к нему обратиться.

### Отличительные черты HTTP

**HTTP** — HyperText Transfer Protocol, протокол передачи гипертекста.

Основные особенности HTTP:

1. **Клиент-серверная модель**

   Клиент отправляет запрос, сервер возвращает ответ.

2. **Отсутствие состояния**

   HTTP сам по себе не хранит состояние между запросами. Каждый запрос считается независимым.

3. **Методы запросов**

   Основные методы:

   | Метод | Назначение |
   |---|---|
   | `GET` | Получение ресурса |
   | `POST` | Отправка данных |
   | `PUT` | Полное обновление ресурса |
   | `PATCH` | Частичное обновление ресурса |
   | `DELETE` | Удаление ресурса |

4. **Коды состояния**

   Сервер возвращает код состояния:

   | Код | Значение |
   |---|---|
   | `200` | Успешный запрос |
   | `201` | Ресурс создан |
   | `400` | Ошибка клиента |
   | `404` | Ресурс не найден |
   | `500` | Ошибка сервера |

5. **Заголовки**

   HTTP-заголовки передают дополнительную информацию о запросе или ответе.

6. **Тело запроса и ответа**

   В теле могут передаваться HTML, JSON, текст, изображения и другие данные.
