### 2.2. Подключение к API

Backend из четвёртой лабораторной запускается на порту `3000`:

```text
http://localhost:3000
```

Frontend пятой лабораторной запускается на другом порту, например `3001`:

```text
http://localhost:3001
```

Из-за разных портов на backend был настроен CORS.

### 2.3. XHR-сервис

Для запросов используется `XMLHttpRequest`, а не `fetch`.

```js
const API_BASE_URL = 'http://localhost:3000/api/rehab-requests';

const sendRequest = (method, url, body = null) => {
    return new Promise((resolve, reject) => {
        const request = new XMLHttpRequest();

        request.open(method, url, true);
        request.setRequestHeader('Content-Type', 'application/json');

        request.onload = () => {
            if (request.status >= 200 && request.status < 300) {
                if (request.status === 204) {
                    resolve(null);
                    return;
                }

                resolve(JSON.parse(request.responseText));
            } else {
                reject({
                    status: request.status,
                    message: request.responseText
                });
            }
        };

        request.onerror = () => {
            reject({
                status: request.status,
                message: 'Ошибка сети'
            });
        };

        request.send(body ? JSON.stringify(body) : null);
    });
};
```

Третий параметр `true` в `request.open(method, url, true)` означает асинхронное выполнение запроса.

### 2.4. Получение списка и фильтрация

Список заявок получается через запрос:

```http
GET /api/rehab-requests
```

Фильтрация выполняется через query-параметры:

```http
GET /api/rehab-requests?equipmentName=кресло
GET /api/rehab-requests?status=в работе
GET /api/rehab-requests?district=Тверской
```

На frontend фильтр преобразуется в строку параметров и отправляется на backend.

### 2.5. Получение одной записи

При открытии страницы подробнее выполняется запрос:

```http
GET /api/rehab-requests/:rehabRequestId
```

Ответ сервера используется для вывода полной информации о заявке.

### 2.6. Добавление записи

На странице формы пользователь вводит данные новой заявки. После отправки формы выполняется запрос:

```http
POST /api/rehab-requests
```

Пример тела запроса:

```json
{
  "applicantName": "Егор Гаврилов",
  "applicantCategory": "инвалид III группы",
  "equipmentName": "опорная трость",
  "district": "Тверской",
  "status": "новая",
  "priority": "обычная",
  "comment": "Нужна выдача в центре социальной поддержки"
}
```

После успешного создания пользователь возвращается на главную страницу.

### 2.7. Редактирование записи

При нажатии на кнопку «Редактировать» открывается та же форма, но поля заполняются текущими данными заявки. После сохранения выполняется запрос:

```http
PATCH /api/rehab-requests/:rehabRequestId
```

Изменённые данные отправляются в JSON-теле запроса.

### 2.8. Удаление записи

При нажатии на кнопку «Удалить» выполняется запрос:

```http
DELETE /api/rehab-requests/:rehabRequestId
```

После успешного удаления список заявок обновляется без перезагрузки страницы.

### 2.9. Асинхронность через setTimeout

Для демонстрации асинхронности на backend можно временно добавить задержку ответа:

```js
const getRehabRequestsList = (request, response) => {
    console.log('1. Сервер получил GET-запрос списка заявок');

    setTimeout(() => {
        console.log('3. Сервер отправляет ответ через 5 секунд');

        const rehabRequests = rehabRequestsService.findAll(request.query);
        response.status(200).json(rehabRequests);
    }, 5000);

    console.log('2. Код после setTimeout выполнился сразу, сервер не заблокировался');
};
```

Во вкладке Network видно, что XHR-запрос находится в состоянии `Pending`, но интерфейс сайта остаётся доступным. Если отправить несколько запросов подряд, они одновременно находятся в `Pending`.

## Контрольные вопросы

### Что такое AJAX

AJAX — это подход, при котором страница обменивается данными с сервером без полной перезагрузки. В данной работе AJAX реализован через `XMLHttpRequest`.

### Что такое XMLHttpRequest

`XMLHttpRequest` — это встроенный браузерный объект для отправки HTTP-запросов из JavaScript. Он позволяет получать данные с сервера асинхронно.

### Почему запросы асинхронные

Вызов:

```js
request.open(method, url, true);
```

содержит третий параметр `true`, который включает асинхронный режим. После `request.send()` код продолжает выполняться, а ответ обрабатывается позже в `request.onload`.

### Что такое CORS

CORS — механизм безопасности браузера, который ограничивает запросы между разными источниками. Так как frontend и backend запущены на разных портах, backend должен вернуть заголовок `Access-Control-Allow-Origin`.

### Какие методы используются

```text
GET — получение списка и одной записи
POST — добавление записи
PATCH — частичное редактирование записи
DELETE — удаление записи
```
