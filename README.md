### 2.1. Структура проекта

### 2.2. Подключение JavaScript

JavaScript подключается к HTML-странице через тег `script`:

```html
<script src="script.js"></script>
```

Код выполняется после загрузки страницы, чтобы все элементы интерфейса были доступны из JavaScript.

### 2.3. Переменные состояния калькулятора

Для хранения состояния калькулятора используются переменные:

```js
let firstNumber = '';
let secondNumber = '';
let selectedOperation = null;
```

`firstNumber` хранит первое число, `secondNumber` — второе число, а `selectedOperation` — выбранную операцию.

### 2.4. Обработка ввода чисел

Для цифровых кнопок назначаются обработчики событий. При нажатии на кнопку цифра добавляется к текущему числу и выводится на экран.

```js
function addDigit(digit) {
    if (selectedOperation === null) {
        firstNumber += digit;
        outputElement.textContent = firstNumber;
    } else {
        secondNumber += digit;
        outputElement.textContent = secondNumber;
    }
}
```

Для кнопки точки выполняется проверка, чтобы нельзя было ввести две точки в одном числе.

### 2.5. Выполнение арифметических операций

После выбора операции калькулятор запоминает её:

```js
function setOperation(operation) {
    if (firstNumber === '') return;
    selectedOperation = operation;
}
```

Кнопка `=` запускает вычисление результата:

```js
function calculateResult() {
    const a = Number(firstNumber);
    const b = Number(secondNumber);
    let result;

    switch (selectedOperation) {
        case '+':
            result = a + b;
            break;
        case '-':
            result = a - b;
            break;
        case '*':
            result = a * b;
            break;
        case '/':
            if (b === 0) {
                outputElement.textContent = 'Ошибка';
                return;
            }
            result = a / b;
            break;
        default:
            return;
    }

    firstNumber = String(result);
    secondNumber = '';
    selectedOperation = null;
    outputElement.textContent = firstNumber;
}
```

### 2.6. Индивидуальная операция

По теме социальной помощи была добавлена индивидуальная операция, встроенная в логику калькулятора без `alert` и без дополнительных окон. Например, операция может рассчитывать итоговую стоимость комплекта технических средств реабилитации с учётом количества или процента компенсации.

Пример операции:

```js
function calculateRehabSupportPercent() {
    const currentValue = Number(firstNumber || outputElement.textContent);
    const result = currentValue * 0.8;
    firstNumber = String(result);
    secondNumber = '';
    selectedOperation = null;
    outputElement.textContent = firstNumber;
}
```

Эта операция использует текущее значение на экране и выводит результат в тот же экран калькулятора.

### 2.7. Очистка и обработка ошибок

Кнопка очистки сбрасывает состояние калькулятора:

```js
function clearCalculator() {
    firstNumber = '';
    secondNumber = '';
    selectedOperation = null;
    outputElement.textContent = '0';
}
```

При делении на ноль выводится сообщение `Ошибка`, после чего пользователь может очистить калькулятор и продолжить работу.

## Контрольные вопросы

### Как связана кнопка `=` с кодом лабораторной

Кнопка `=` получает обработчик события `onclick` или `addEventListener`. При нажатии вызывается функция вычисления результата, которая берёт первое число, второе число и выбранную операцию, затем выводит результат на экран.

### Что происходит при сложении двух чисел

1. Пользователь нажимает цифры первого числа.
2. JavaScript сохраняет их в переменную `firstNumber`.
3. Пользователь нажимает кнопку `+`.
4. В переменную `selectedOperation` записывается `+`.
5. Пользователь вводит второе число.
6. Оно сохраняется в `secondNumber`.
7. Пользователь нажимает `=`.
8. Функция переводит строки в числа через `Number()`.
9. Выполняется сложение.
10. Результат выводится на экран.

### Класс кнопки, которая выводит количество нажатий

```js
class ClickCounterButton {
    constructor(buttonElement) {
        this.buttonElement = buttonElement;
        this.clickCount = 0;
    }

    init() {
        this.buttonElement.addEventListener('click', () => {
            this.clickCount += 1;
            this.buttonElement.textContent = `Нажато: ${this.clickCount}`;
        });
    }
}
```

### Код поиска максимального элемента в массиве

```js
const numbers = [4, 12, 7, 3, 18, 1];
let maxNumber = numbers[0];

for (let i = 1; i < numbers.length; i += 1) {
    if (numbers[i] > maxNumber) {
        maxNumber = numbers[i];
    }
}

console.log(maxNumber);
```
