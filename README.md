## Выполнение работы

### 2.1. Структура проекта

Проект имеет компонентную структуру:

```text
lab3/
  components/
  pages/
  img/
  index.html
  main.js
  package.json
  style.css
```

Папка `components` содержит переиспользуемые элементы интерфейса, а папка `pages` — страницы приложения.

### 2.2. Подключение Node.js и npm

В проекте используется `package.json`, где описаны зависимости и команды запуска. Для установки зависимостей используется команда:

```bash
npm install
```

Для запуска проекта используется локальный сервер:

```bash
npm start
```

### 2.3. Главная страница со списком услуг

Главная страница выводит список карточек по теме социальной помощи и технических средств реабилитации. Каждая карточка содержит изображение, название услуги, краткое описание и кнопки управления.

Пример карточки:

```html
<div class="card">
    <img src="img/items.png" class="card-img-top" alt="Услуга">
    <div class="card-body">
        <h5 class="card-title">Кресло-коляска</h5>
        <p class="card-text">Выдача технического средства реабилитации.</p>
        <button class="btn btn-primary">Подробнее</button>
    </div>
</div>
```

### 2.4. Mock-данные

Данные хранятся в виде массива объектов. Это имитирует получение данных от backend, но без реального сервера.

```js
const rehabServices = [
    {
        id: 1,
        title: 'Кресло-коляска',
        shortText: 'Выдача технического средства реабилитации',
        fullText: 'Подробная информация об услуге',
        images: ['img/items.png']
    }
];
```

В данных используются тематические названия, а не абстрактные `item`, `text`, `product`.

### 2.5. Фильтрация карточек

Фильтрация выполняется по названию или описанию услуги. Пользователь вводит текст в поле поиска, после чего список карточек перестраивается.

```js
const filteredServices = rehabServices.filter((service) => {
    return service.title.toLowerCase().includes(searchValue.toLowerCase());
});
```

### 2.6. Страница подробнее

При нажатии на кнопку «Подробнее» открывается страница с подробной информацией об услуге. На ней отображаются изображения, полное описание и контактная информация.

Страница получает объект выбранной услуги и выводит его данные:

```js
const productPage = new ProductPage(rootElement, serviceData);
productPage.render();
```

### 2.7. Добавление и удаление карточек

Кнопка добавления копирует первую карточку и добавляет её в список:

```js
const copiedService = {
    ...rehabServices[0],
    id: Date.now(),
    title: `${rehabServices[0].title} — копия`
};
```

Кнопка удаления удаляет выбранную карточку из массива и перерисовывает список.

```js
services = services.filter((service) => service.id !== removedServiceId);
```

В хедере и на странице подробнее есть кнопка «Домой». Она возвращает пользователя на главную страницу приложения.


## Контрольные вопросы

### Структура проекта

Проект разделён на `components`, `pages`, файлы стилей, изображения и точку входа `main.js`. Такой подход упрощает поддержку кода, потому что каждый компонент отвечает за отдельную часть интерфейса.

### Что такое MVC

MVC — это архитектурный подход, который делит приложение на три части:

* Model — данные и бизнес-логика;
* View — отображение данных пользователю;
* Controller — обработка действий пользователя и связь между моделью и отображением.

В данной лабораторной mock-данные играют роль модели, компоненты страницы — роль view, а обработчики событий — роль controller.

### Что такое роутинг

Роутинг — это механизм выбора страницы или обработчика в зависимости от текущего пути или действия пользователя. В данной работе роутинг реализован на уровне JavaScript: при клике на карточку вместо главной страницы отрисовывается страница подробной информации.

### Ключевые этапы рендера

1. Браузер получает HTML.
2. Строится DOM-дерево.
3. Загружаются CSS и JavaScript.
4. JavaScript создаёт компоненты.
5. Компоненты добавляют HTML-разметку в DOM.
6. Браузер отрисовывает итоговый интерфейс.
